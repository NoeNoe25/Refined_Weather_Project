# Weather App (Vanilla JavaScript)

A weather app built with plain HTML, CSS and JavaScript. Search a city to see current conditions and a 5-day forecast. The page background changes to match the weather.

**Live demo:** https://benevolent-tanuki-f00e59.netlify.app

## Features

- Current temperature, description, humidity, wind speed and local time
- 5-day forecast with daily highs and lows
- Background gradient that changes with the weather (clear sky, rain, snow, mist, clouds, thunderstorm)

## Tech stack

HTML5 · CSS3 · JavaScript (ES6) · Axios · SheCodes Weather API

## Files

| File | Purpose |
| --- | --- |
| `index.html` | Page structure and search form |
| `styles.css` | Layout and styling |
| `index.js` | API calls, DOM updates, forecast rendering, background switching |

## Run locally

No build step is needed. Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Notes

Built during the SheCodes course. The API key in `index.js` is the course-provided demo key.
